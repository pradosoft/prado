## Overview
The page edge of a [TDrawer](./TDrawer.md), rendered as `data-placement` in lower case. Start and End follow the text direction.

| Value | `data-placement` | The drawer shows at | Docks with `DockAt` |
|---|---|---|---|
| `Start` | `start` | the inline start; left in a left-to-right page | yes |
| `End` | `end` | the inline end; right in a left-to-right page | yes |
| `Top` | `top` | the top | no |
| `Bottom` | `bottom` | the bottom, as a bottom sheet | no |

**@since 4.4.0**
