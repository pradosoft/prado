**Namespace:** `Prado\Web\UI\WebControls`

## Overview
TLinkTagCollection is the `LinkTags` collection of a THead control. It extends TList and accepts only TLinkTag objects; another item throws `linktagcollection_linktag_invalid`.

## Key Methods

- `insertAt()` - Inserts a TLinkTag at the specified position
- `findIndexByID()` - Finds the index of a link tag by ID
- `findLinkTagByID()` - Finds a link tag by ID
