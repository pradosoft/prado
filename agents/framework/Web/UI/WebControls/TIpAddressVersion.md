## Overview
The IP address versions that [TIpAddressValidator](./TIpAddressValidator.md) accepts.

| Value | Accepts |
|---|---|
| `Any` | IPv4 and IPv6 addresses |
| `IPv4` | dotted decimal IPv4 addresses |
| `IPv6` | IPv6 addresses, including the IPv4-mapped form `::ffff:a.b.c.d` |

**@since 4.4.0**
