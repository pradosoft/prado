## Overview
TDataGridSortDirection defines the direction of a TDataGrid sort: `TDataGrid.SortDirection` and `TDataGridSortCommandEventParameter::getSortDirection()`. It renders lowercase as the header cell's `aria-sort`.

## Constants

- `Ascending` - Lowest value to highest
- `Descending` - Highest value to lowest
