## Overview
TUrlMappingPatternUrlMatchMode defines the enumerable type for the part of the URL that `TUrlMappingPattern::getPatternMatches()` matches the pattern against.

## Key Properties/Methods

- `PathInfo` (default) - Match the PATH_INFO, the part of the URL after the entry script and before the question mark
- `Full` - Match the PATH_INFO and the query string, separated by a question mark
